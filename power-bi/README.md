# Power BI Reports

The project contains two Power BI dashboard pages built on top of the dimensional data warehouse.

## Dashboard 1 — Sales Performance

The first dashboard focuses on:

- Overall sales KPIs
- Revenue by product category
- Revenue trends over time
- Top-selling products
- Weekday vs. weekend sales
- Average order value analysis

## Dashboard 2 — Territory Analysis

The second dashboard focuses on:

- Revenue by city
- Geographic distribution of sales
- Average purchase value by city
- Territory-level comparisons
- Sales trends across selected cities

The original Power BI `.pbix` file is not included in this repository because of its large file size.

Dashboard previews are available in the `screenshots` directory.
