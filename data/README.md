# Dataset

This project uses the Grocery Sales Dataset available on Kaggle.

Dataset source:

https://www.kaggle.com/datasets/andrexibiza/grocery-sales-dataset

The dataset contains grocery retail data including sales transactions, products, customers, cities, countries, categories, and related business entities.

The raw SQL Server database backups are not included in this repository because of their large file size.

The source data was transformed into a dimensional data warehouse using SQL Server Integration Services (SSIS).
